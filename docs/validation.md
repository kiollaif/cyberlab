# Проверка прототипа 0.1.0

Фактически проверено в облачной Linux x86_64: Python 3.12.14, PySide6 6.12.0,
uv 0.12.23. Qt запускался с платформой `offscreen`, без физического дисплея.

| Проверка | Результат |
| --- | --- |
| `uv sync --locked` | Установка и повторная синхронизация успешны |
| `uv pip check --python .venv/bin/python` | Все 15 установленных пакетов совместимы |
| `uv run --locked pytest -q` | **28 passed**, без пропусков и ожидаемых падений |
| `uv run --locked ruff check .` | Успешно |
| `uv run --locked ruff format --check .` | Успешно |
| `git diff --check` | Успешно |
| `uv build` | Собраны sdist и wheel `cyberlab-0.1.0` |
| Wheel в отдельном venv, запуск из `/tmp` | Окно Qt, цикл событий, выбор решения и сравнение работают |
| `python -m cyberlab --help` из установленного wheel | Точка входа работает |

Проверки приложения используют временные базы и не меняют пользовательскую историю.
Автоматические тесты проверяют:

- все восемь маршрутов к четырём итогам сценария;
- ветвление после возврата и неизменность старого снимка;
- повтор решения без дубликатов;
- закрытие и повторное открытие SQLite с восстановлением веток и активного шага;
- невозможность привязать шаг к чужой сессии;
- полный откат нового снимка при ошибке обновления активного указателя;
- отказ от неизвестной версии схемы без потери данных;
- нажатия кнопок Qt, переход через дерево, состояние файлов и сравнение;
- сворачивание сравнения на маленьком экране;
- запуск точки входа с настоящим циклом событий Qt.

Компоновка визуально проверена на снимках окон 1120×720 и 1440×940.
[Снимок интерфейса](cyberlab.png) показывает две альтернативные ветки.

## Что ещё не проверено

Windows не запускалась в текущей Linux-среде. Workflow `.github/workflows/checks.yml`
настроен на Python 3.12 в Windows и Ubuntu: системный Qt-плагин Windows и X11/Xvfb
на Linux. Он выполнится после отправки кода в GitHub. Удалённые результаты CI здесь
не получены; локальные headless-тесты не подтверждают работу всех графических драйверов.

Установщик Windows, упакованный Linux-дистрибутив и проверка на физических рабочих
станциях не входят в первый прототип. Сейчас приложение запускается из Python-окружения.
