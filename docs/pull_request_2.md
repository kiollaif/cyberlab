CyberLab получает полный учебный цикл: выбор темы, вымышленный источник, решение, объяснение последствия, итог и проверка альтернативы без потери прежнего пути.

Реализованы шесть тем и 47 маршрутов; сложность и учебные цели; вводный урок; интерактивная схема причин и последствий; оценка решений и график риска; история каждого завершённого варианта с фильтром; локальный помощник на правилах и словарь терминов; настоящий PDF с кириллицей и TXT по выбранному пути.

Сохранены виртуальный ПК, возврат, сравнение, старые SQLite v1 и необязательный асинхронный API. Новые SQL-таблицы не нужны: оценка выводится из сохранённых решений. Упаковка обновлена до 2.0.0b1, smoke-проверка EXE/AppImage проходит шесть сценариев, PDF/TXT, статистику и повторное открытие базы без сети.

Локально выполнены 194 теста offscreen и 194 xcb/Xvfb, Ruff, сборка и офлайн-установка wheel, сборка PyInstaller и запуск бинарного файла без Python/uv в PATH. Windows и Linux CI приведены в docs/cyberlab2.md вместе с фактическими результатами и исправлением узкого окна Windows.

Для кода 3b3af9b успешно завершены Checks 42506205335 и Desktop builds 42506205331: Windows EXE/установщик с проверкой ярлыков, запуска и удаления; Ubuntu AppImage через FUSE и офлайн-контейнер; KWin/GNOME Shell X11; RPM-кандидат в контейнере ALT p11. Ссылки на готовые файлы находятся в README.md и docs/desktop.md.

Физические Windows 10/11, Альт Образование и живой API вручную не проверялись. Локальная нейросеть не включена и не выдаётся за готовую функцию. Отчёт, проверка пути новичка, снимки экранов и оставшиеся ограничения: docs/cyberlab2.md.
